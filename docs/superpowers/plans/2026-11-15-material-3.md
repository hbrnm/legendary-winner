# Material 3 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** Redesign every Cămara screen with the approved natural-green Material 3 identity.
**Architecture:** Adapt shared React components and semantic Tailwind tokens, then page compositions. Keep routes, storage, services and server interfaces intact.
**Tech Stack:** Next.js, React, TypeScript, Tailwind, Vitest, Playwright.
**Spec:** docs/material-3-design.md

## Global Constraints
DM Sans locally hosted; Romanian copy retained; light/dark/system; 360 px minimum; no backend changes; no new UI dependencies; no production deployment.

## Review Focus
- Long Romanian names and amounts must wrap without hiding actions.
- Keyboard and safe areas must not cover sheet footers or shopping actions.
- Tablet rail must preserve access to settings and active navigation.
- Offline font loading and theme persistence must remain intact.
- Selected states must remain legible in both color schemes.
